uw config validate:  PASS (positive + negative)
-------------------------------------------------------------------------------
  IMPORTANT (2.16.x behavior): `uw config validate --schema-file` expects a JSON
  schema file. validator.py does json.loads(schema_file.read_text()), so a YAML
  schema raises:
    json.decoder.JSONDecodeError: Expecting value: line 1 column 1 (char 0)
  This is NOT a VE/install problem — it is the documented schema-file format
  requirement. Real uw-aigfs driver schemas (*.jsonschema) are already JSON, so
  this is only a gotcha for ad-hoc test schemas. Use a .json schema.

  positive (valid config vs. /tmp/mini_schema.json):
    uw config validate --schema-file /tmp/mini_schema.json --input-file /tmp/mini.yaml
    INFO Schema validation succeeded for config

  negative (account removed, /tmp/mini_bad.yaml):
    uw config validate --schema-file /tmp/mini_schema.json --input-file /tmp/mini_bad.yaml
    ERROR 1 schema-validation error found in config
    ERROR Error at platform:
    ERROR   'account' is a required property

  Confirms validate executes correctly and reports the precise error location.
